# Спектр-Диагностика · MedAI — медицинский сервис с ИИ

Версия для клиники «Спектр-Диагностика» (федеральная сеть медицинских центров, spdmed.ru).


Пользователь вводит показатели здоровья (давление, пульс, температура, SpO₂, вес, сон, шаги, вода),
а гибридный ИИ анализирует их и даёт рекомендации:

1. **База правил** — детерминированная экспертная система по медицинским нормам (ВОЗ/ESC/ESH):
   статусы `ok / warn / alarm` по каждому показателю, перекрёстные правила-комбинации,
   итоговый риск `green / yellow / red`.
2. **Языковая модель** (опционально) — персональный текст рекомендаций через OpenAI-совместимый API.
   Ключа нет / ошибка / таймаут → приложение честно пишет «ИИ-текст недоступен» и показывает нормы.
   **LLM не может изменить оценку риска** — её определяют только правила.

Сервис не ставит диагнозы и не заменяет врача; дисклеймер показывается на каждом анализе,
тревожные значения всегда ведут к совету обратиться к врачу (при критических — 103).

## Версия для клиники

- **Кабинет врача** — врачи видят общий пул пациентов клиники: последний риск каждого пациента,
  раздел «Требуют внимания» (последний анализ красный), полный разбор замеров и комментарии,
  которые пациент видит у себя на странице результата.
- **Роли** — пользователи делятся на `patient` (по умолчанию) и `doctor`. Врачом можно стать
  только по одноразовому **коду приглашения** при регистрации.
- **Генерация кодов** (админ клиники, из корня репозитория):

  ```bash
  python tools/make_invite.py      # 1 код
  python tools/make_invite.py 5    # 5 кодов
  ```

- **Бренд и контакты** меняются в одном месте — `frontend/src/brand.ts` (название, подзаголовок,
  телефон, сайт, логотип `assets/spektr-logo.png`).
- **Приватность**: LLM-обогащение выключено по умолчанию — показатели пациентов не уходят
  на внешние API без явного решения клиники.

## Стек

- **Backend**: Python 3.13 + FastAPI + SQLite (WAL), pbkdf2-хэши паролей, bearer-сессии
- **Frontend**: React 18 + TypeScript + Vite + Tailwind 4, графики recharts
- **Дизайн**: дизайн-система Flip7 (ретро-игривый teal-coral-gold: pill-кнопки с золотым градиентом
  и глянцем, cream-инпуты, цветные glow-тени, левые акцент-полосы карточек, dashed-разделители)

## Запуск

### Backend

```bash
cd backend
pip install -r requirements.txt
copy .env.example .env        # опционально: вписать LLM_API_KEY
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Если есть сборка фронтенда (`frontend/dist`), бэкенд сам раздаёт её — приложение целиком
открывается на http://127.0.0.1:8000 (SPA-fallback для роутов).

### Frontend (режим разработки)

```bash
cd frontend
npm install
npm run dev    # http://localhost:5173, /api проксируется на :8000
```

### Прод-сборка одним сервером

```bash
cd frontend && npm run build   # создаст dist/
cd ../backend && python -m uvicorn app.main:app --port 8000
```

### Подключение ИИ-текста

В `backend/.env`:

```env
LLM_API_KEY=sk-...            # OpenAI, OpenRouter, DeepSeek и т.п.
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o-mini
```

После перезапуска бэкенда в анализе появится блок «Рекомендации ИИ» с персональным текстом.

## Медицинские пороги правил (кратко)

| Показатель | Норма | Внимание (warn) | Тревога (alarm) |
|---|---|---|---|
| Давление | до 120/80 | 130–139/85–89, АГ 1 ст. (140–159/90–99), <90/60 | ≥160/100, ≥180/110, <85/50 |
| Пульс | 60–100 | 50–59, 101–120 | <50, >120 |
| Температура | 36.1–37.0 | 37.1–38.0, 36.0–36.1 | >39.0, >38.0, <35.0 |
| SpO₂ | 95–100 | 92–94 | <92 → срочно 103 |
| ИМТ | 18.5–24.9 | <18.5, 25–35 | <16, >35 |
| Сон | 7–9 ч | <7, >9 | — |
| Шаги | ≥3000, цель 8000–10000 | <3000 | — |
| Вода | ~30 мл/кг (≈2000 мл) | <1200, >4000 | — |

Комбинации: жар + учащённый пульс → инфекция; давление + пульс → стресс/кофеин;
недосып + высокое давление; лишний вес + низкая активность; гипотония + обезвоживание.

## Структура

```
medai/
├── backend/
│   ├── app/
│   │   ├── main.py               # FastAPI, CORS, раздача SPA
│   │   ├── config.py             # настройки из .env
│   │   ├── database.py           # SQLite WAL: users, sessions, measurements, analyses
│   │   ├── auth.py               # pbkdf2 + bearer-токены
│   │   ├── schemas.py            # Pydantic-модели с валидацией диапазонов
│   │   ├── routers/              # auth · measurements · stats
│   │   └── services/
│   │       ├── rules.py          # движок правил (нормы, комбинации, риск)
│   │       ├── llm.py            # OpenAI-совместимый адаптер + fallback
│   │       └── analyze.py        # оркестратор
│   └── tests/test_rules.py       # pytest
└── frontend/
    └── src/
        ├── styles/theme.css      # токены Flip7 (1rpx → 0.5px)
        ├── api.ts · auth.tsx · types.ts
        ├── components/           # Layout · IndicatorCard · RiskBadge · Disclaimer · Confetti
        └── pages/                # Login · Register · Dashboard · NewMeasurement · Result · History · Profile
```

## API (кратко)

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/auth/register` | регистрация → token |
| POST | `/api/auth/login` | вход → token |
| GET/PUT | `/api/auth/me` | профиль (возраст, пол, рост — для норм и ИМТ) |
| POST | `/api/measurements` | создать замер + сразу получить анализ |
| GET | `/api/measurements` | история (пагинация) |
| GET/DELETE | `/api/measurements/{id}` | анализ замера / удаление |
| GET | `/api/stats` | ряды для графиков динамики |
| GET | `/api/health` | `{ok, llm_enabled}` |
